## 2. Модели и качество

### Claude Sonnet 5.5 / Opus 5.5
- **Основной источник**: Страница запуска Anthropic, 28.09.2026 (данные вендора)
  - Terminal-Bench: Sonnet 5.5 — 70.6%, Opus 5.5 — 66.4%
  - Подтверждено websearch-сниппетом по запросу "Claude Sonnet 5.5 coding reviews Terminal-Bench"
- **Тип**: данные вендора (опубликованные бенчмарки)
- **Перенос между задачами**:
  - Terminal-Bench (автономные терминальные задачи) → задача 5 (реализация с инструментами): прямая применимость для агентных циклов
  - Terminal-Bench 70.6% → задача 2 (HTML/CSS верстка) и задача 6 (ревью): косвенный перенос — Terminal-Bench не тестирует специфически вёрстку и код-ревью, используется как общий показатель возможностей кодинга
  - Уверенность для задач 2 и 6: **предварительная** — прямых бенчмарков по вёрстке/ревью для Sonnet 5.5 не найдено
- **Оговорки**: Результат Opus 5.5 (66.4%) ниже Sonnet 5.5 (70.6%) на Terminal-Bench. Это интерпретируется вендором как специализация — не деградация; Opus 5.5 позиционируется для более глубоких рассуждений. Для задач типа "умный ревьювер/архитектор" используем Opus 5.5 именно по рассуждательной специализации, не по Terminal-Bench.

  - Terminal-Bench 1017: 42.3%

  - Automation-Bench: 60.5%
  - Подтверждено websearch-сниппетом по запросам "DeepSeek V4.1 Flash agentic reviews" и "DeepSeek Flash coding benchmark"
- **Тип**: данные вендора (опубликованные бенчмарки)
- **Перенос между задачами**:
  - DeepSWE 77% → задача 3 (скрипты/компоненты), задача 5 (реализация): высокая применимость для реального кодинга

- **Оговорки**: DeepSWE — синтетический бенчмарк, реальные результаты могут отличаться. Версия "V4.1 Flash 1017" vs "V4.1 Flash" — уточнить актуальный API ID при подключении.
