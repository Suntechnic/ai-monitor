Для Go API применяется endpoint с `/inference/go/`, а в селекторе OpenCode — `opencode-go/<model-id>`. Указанные API ID не содержат префикс клиента.

Для простого вызова Haiku 2000/500 расход allowance $0.00045; для кода 12000/3000 — $0.0027. Это не доплата и не денежная стоимость включённого вызова. Один полный месячный allowance арифметически покрывает около 5555 условных кодовых вызовов без кеша, но 5-часовой лимит — около 1111, общий расход на другие задачи уменьшает оба остатка. Эти оценки не равны опубликованным рекламным количествам запросов, основанным на больших cache hits.

Go рассчитан на обычный трафик coding-агентов, требует идентификации клиента и стабильной сессии. Extra Usage может переключать на платный баланс после исчерпания квоты; этот режим не включён в рекомендации. Sonnet и Opus не перечислены в Go, поэтому рекомендованы только через OpenRouter. Бесплатные модели и временные free-акции исключены. Платная акция Gemini 4 Argon 50% до 30.11.2026 относится к другим кандидатам, не к выбранным ставкам. Таблица pay-as-you-go из исходного opencode.html не использована как тариф Go.
