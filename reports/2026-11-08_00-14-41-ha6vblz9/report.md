**Практика применения:**

- **Простые ответы:** держите Haiku на low/medium effort — высокая скорость достаточна для справок. Luna направляйте там, где Go-квота нужна для кода.
- **Вёрстка:** передавайте скриншот, HTML и CSS; просите минимальный diff. MiniMax M3.1 Flash — только для точечных правок классов/отступов по чёткому ТЗ из-за высокого hallucination rate. Sonnet при неудаче эскалируйте в Opus с конкретным дефектом.
- **Небольшой код:** DeepSeek напрямую дешевле всех при сопоставимом качестве; сохраняйте `reasoning_content` между ходами — иначе tool-calling ломается. GLM-5.3-Flash используйте в Go, пока хватает квоты.
- **Планирование и реализация:** Kimi для больших репозиториев и длинных сессий; DeepSeek Flash для прямых изменений с инструментами. Opus подключайте на неоднозначные миграции и критичные рефакторинги.

Все суммы — условный вызов без кеша: простые 2000/500, вёрстка 8000/2000, код 12000/3000, проект 50000/8000 токенов.

## Новости

- **DeepSeek V4.1 Flash 1017 лидирует в агентных бенчмарках:** Terminal-Bench 4.0 42.3% (лучший результат среди всех моделей), DeepSWE 1.1 77%, Automation-Bench 60.5%, Agents' Last Exam 35.4% — удвоение результата исходного V4.1 Flash при той же цене. Подтверждено независимыми тестами, модель стала основным конкурентом Claude Opus 5 на агентных задачах.
- **OpenCode Go увеличил квоту DeepSeek V4.1 Flash в 4 раза:** лимит с $15/мес до $60/мес (Go) и с $7.50/мес до $30/мес (Go Plus). Новые цены подтверждены в документации 05.11.2026. MiniMax M3.1 Flash добавлен в Go с лимитом $36/мес (Go), Claude Haiku 5.5 — $15/мес (Go).
- **MiniMax M3.1 Flash: сильные бенчмарки с высоким hallucination rate:** Intelligence Index 43, стоимость $0.22/задача, но Artificial Analysis зафиксировал 93% hallucination rate. Подходит только для правок с проверяемым результатом, а не для генеративной работы.
- **Gemini 4 Argon скидка -50% до 30.11.2026:** после этой даты цена вырастет с $2/$10 до $4/$20 за 1M токенов. OpenCode Go и OpenRouter включают модель; ранние отзывы смешанные — сильные результаты на сложных задачах, но часть разработчиков отмечает проблемы на кодинге.
- **Claude Sonnet 5.5 с 28.09.2026 обгоняет Opus 5.5 на Terminal-Bench 4.0:** 70.6% против 66% у Opus 5.5 при той же цене $2/$10. Отзывы CodeRabbit подтверждают сокращение времени ревью в два раза и снижение стоимости на 40% против Sonnet 5. Стал основным кандидатом вместо Opus 5.5 для большинства задач.

## Изменения

- Задача разделена на три роли: планирование (анализ, архитектура, декомпозиция), реализация (изменение файлов, соблюдение требований) и проверка (ревью, тесты, поиск ошибок). Это точнее соответствует практическому использованию агентов в проектном цикле.
- Основная реализация переходит с Kimi K3.1 Pro на DeepSeek V4.1 Flash 1017: цена условного вызова снижается с $0.18 до $0.0072 (peak) / $0.0036 (off-peak), при этом агентные бенчмарки показывают равное или лучшее качество.
- Ревью и проверка берут Claude Sonnet 5.5 как основной выбор: сильная точность по отзывам, стоимость $0.036/вызов оправдана для критичной задачи выявления ошибок.
- MiniMax M3.1 Flash оставлен в роли бюджетного для вёрстки, но с жёстким ограничением: только правки по точному ТЉ из-за 93% hallucination rate. Для генеративной работы не подходит.
- GPT-6.1 Terra добавлен как бюджетный вариант проверки: $0.018/вызов, вдвое дешевле Sonnet 5.5, годится для первого прохода ревью с эскалацией на сложных случаях.
