## Слабые места и разногласия

- Vantyr предупреждает о сбоях и отказах API; низкая цена не равна стабильности. Для профиля администрирования полный расчёт прямого официального DeepSeek дешевле OpenRouter snapshot для версии Flash 1017; OpenRouter остаётся агрегированным маршрутом, а прямой API предоставляет ясный тариф peak/off-peak и документированное соответствие API ID текущей версии.
- Для OpenRouter тарифа DeepSeek в snapshot единицы конвертированы из USD за токен в USD/1M. Значения отражены без утверждения, что каждый backend маршрута выставит одинаковую стоимость.
- Go включён в платную подписку и ограничен модельными квотами; фактический тариф и возможность выбрать конкретную модель у пользователя не подтверждены.
- По нескольким профилям типовые input/output/cache_read взяты строго из локального `profiles.yml`; стоимость не является прогнозом для произвольной сессии.
