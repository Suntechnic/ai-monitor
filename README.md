# ai-monitor

Мониторинг новостей ИИ и цен DeepSeek, OpenRouter, OpenCode Console.
Без планировщика: один запуск создаёт Markdown-отчёт.

## Требования

Linux, Python 3.9+, OpenCode v2 в PATH. Python-пакеты не нужны.
Модель по умолчанию: `opencode/glm-5.3-flash-free` (GLM 5.3 Flash Free от OpenCode).
Она должна быть доступна в вашем OpenCode. Поиск: подключённый Tavily;
в глобальном конфиге `"websearch": {"provider": "tavily"}`.
Ключи берутся из существующих подключений OpenCode, в репозитории не хранятся.

## Запуск

```bash
git clone https://github.com/Suntechnic/ai-monitor.git
cd ai-monitor
python3 ai_monitor.py
```

Новости по умолчанию за 7 дней. Настройки:

```bash
python3 ai_monitor.py --days 1 --timeout 1800
python3 ai_monitor.py --model tokenator/free-glm-5.3-flash
```

Без `--allow-paid-model` разрешены только модель по умолчанию и `tokenator/free-*`.
Проверка ID не гарантирует неизменность тарифов: проверяйте условия провайдеров.
Tavily тарифицируется отдельно: лимит 8 поисков задан промптом, не программно;
число кредитов не обязательно равно числу запросов.

## Результаты

`reports/` — отчёты; `runs/` — исходные данные, промпт и opencode.log.
При успехе stdout содержит путь отчёта, код выхода 0. При ошибке код 1,
старые отчёты не перезаписываются. Параллельные запуски блокируются.
Снимки официальных страниц и JSON OpenRouter дополняются поиском Tavily.
Предыдущий отчёт передаётся для сравнения изменений.
Структурная проверка не подтверждает фактическую точность; это рекомендации,
а не собственные тесты моделей. Реальный запуск с вашими ключами проверяется локально.

## Безопасность

Используется --auto: разрешения, не запрещённые явно, одобряются автоматически.
Рабочая папка отдельная, но НЕ sandbox. Запрет shell-команд в промпте не является
техническим ограничением. Используйте непривилегированного пользователя и
ограничения инструментов OpenCode. Не запускайте от root.
Скрипт не меняет глобальную конфигурацию, не устанавливает расписание,
не подключает платные тарифы. Результаты и логи исключены из Git.
