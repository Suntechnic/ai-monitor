# ai-monitor

Короткий мониторинг ИИ для PHP/JS/Vue/HTML/CSS: DeepSeek, OpenRouter, OpenCode Go, Токенатор, Vantyr.
Планировщик не включён. Linux, Python 3.9+, OpenCode v2, PyYAML.

## Запуск

Установите зависимости: `python3 -m pip install -r requirements.txt`.
Скопируйте `vars.example.yml` в `providers.yml`, если локального конфига ещё нет.
В `providers.yml` настраиваются URL, формат, название и условия доступа каждого поставщика.
Поле `token` необязательно; если задано, скрипт отправляет `Authorization: Bearer <token>`.
Другой конфиг можно выбрать через `--config /absolute/path/providers.yml`.
`providers.yml` исключён из Git; в manifest и промпт ключи не копируются.

Задачи и их токенные профили описаны в `profiles.yml` (коммитится в Git):
`title` — название задачи, `input` / `output` / `cache_read` — оплачиваемые
токены условной задачи (типовой сессии целиком), `note` — происхождение цифр.
Чтобы добавить задачу, добавьте профиль — число строк таблицы в отчёте
изменится само. Цифры откалиброваны по средним реальных сессий OpenCode
(`opencode api get /api/session`) и обновляются вручную.
Другой файл профилей: `--profiles /absolute/path/profiles.yml`;
`--dry-run` готовит снимки, manifest и промпт и выходит до запуска OpenCode.

## Пометки сессий и калибровка

Числа в `profiles.yml` — средние по реальным сессиям. Чтобы накапливать
данные, помечайте сессии тегом — он хранится в `metadata.tag` сессии
OpenCode и читается из `/api/session` вместе с токенами:

```bash
python3 session_stats.py list              # все сессии: тег, папка, токены, $
python3 session_stats.py tag last php      # пометить последнюю сессию
python3 session_stats.py tag <id-префикс> php-tosir
python3 session_stats.py tag <id-префикс> -   # снять тег
python3 session_stats.py stats             # средние по тегам: вход/кеш/выход
python3 session_stats.py show <id-префикс> # сырые поля сессии
```

Рекомендуемые теги: `admin`, `ii`, `scripting`, `php`, `php-tosir`.
Порядок работы: завершили задачу — `tag last <тег>`; накопилось — `stats`
и перенос средних в `profiles.yml` (колонки stats соответствуют `input`,
`cache_read` и `output+reasoning`). Теги локальны для машины: статистику
с других машин перенесите вручную или соберите тем же скриптом там.

В OpenCode должна быть доступна `opencode/glm-5.3-flash-free` (по умолчанию).
Подключите Tavily и задайте в глобальном конфиге
`"websearch": {"provider": "tavily"}`. Ключи в репозитории не хранятся.

```bash
python3 ai_monitor.py
python3 ai_monitor.py --days 1
python3 ai_monitor.py --model tokenator/free-glm-5.3-flash
```

## Результат

Каждый запуск создаёт папку `reports/<дата-время-суффикс>/` и копирует её содержимое в `reports/actual/`:

- `report.md` — таблица рекомендаций: по 2 роли на каждый профиль из `profiles.yml`, новости и изменения.
- `prices.md` — подробные цены, условия и расчёты.
- `sources.md` — источники, отзывы и основания оценок.

Поставщик и точный API ID обязательны для каждой рекомендации.
При отсутствии профильных бенчмарков агент использует отзывы и косвенные данные,
отмечая уверенность, но всё равно выбирает практический вариант.
Промпт редактируется отдельно в `prompt.md`.
Цены сначала берутся из загруженных снимков; недостающие сведения проверяются
по официальным URL. Поиск качества выполняется для уникальных моделей,
а цены и условия проверяются отдельно для выбранных поставщиков.

Старые одиночные отчёты `reports/*.md` также учитываются при сравнении.
Для сравнения берётся отчёт с самым свежим временем изменения файла.
Исходные снимки, manifest, промпт и opencode.log сохраняются в `runs/`.
Три файла публикуются одной операцией только после структурной проверки всех трёх.
Код выхода 0 и путь report.md означают успешную публикацию; при ошибке код 1.
Параллельные запуски блокируются. Фактическая корректность не гарантируется
структурной проверкой; реальное подключение проверяется локальным запуском.

## Расходы и безопасность

Без --allow-paid-model разрешены только модель по умолчанию и tokenator/free-*.
Имя модели не гарантирует неизменность тарифа. Tavily расходует отдельные кредиты.
До 8 поисков — инструкция агенту, а не технический лимит.
Используется --auto, отдельная рабочая папка НЕ sandbox. Запрет shell-команд
в промпте не является техническим ограничением. Не запускайте от root;
используйте ограничения инструментов и непривилегированного пользователя.
Скрипт не меняет глобальную конфигурацию и не подключает платные тарифы.

## Рекомендуемые провайдеры

[Токенатор](https://tokenator.cloud/?ref=760f8922)
- Очень большой выбор моделей
- Оплата рублями
- Есть дневной бесплатный лимит доступа к сильным моделям, в т.ч. Claude Opus 5.5 и Gemini 4 Argon
- Поддержка в Telegram на русском

[Vantyr](https://vantyr.xyz/sign-up?aff=wj46)
- Модели OpenAI и Anthropic
- Оплата криптой или иностранной картой
- Очень низкие цены
- Нестабильная доступность (бывают обрывы и отказы API), моделей мало

[DeepSeek](https://platform.deepseek.com/)
- Прямой поставщик
- Оплата иностранной картой
- Очень низкая цена за вполне приемлемую модель, особенно в OFF_PEAK (с 16:30 до 00:30 UTC, то есть с 19:30 до 03:30 по МСК (UTC+3))

[OpenRouter](https://openrouter.ai/)
- Очень много моделей
- Оплата иностранной картой
- При внесении однократно 10$ на счет, увеличиваются дневные лимиты на бесплатных моделях в 20 раз
- Среди бесплатных моделей нет ничего примечательного

[OpenCode](https://opencode.ai/)
- Есть подписка от 10$ с раздельными лимитами для моделей
- Оплата иностранной картой
- Моделей много, но в подписке флагманов OpenAI и Anthropic нет.
