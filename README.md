# ai-monitor

Локальный мониторинг новостей ИИ и цен DeepSeek, OpenRouter и OpenCode Console.
Планировщик не включён: один запуск создаёт один Markdown-отчёт.

## Требования

Linux, Python 3.9+, OpenCode v2 в PATH. Сторонние Python-пакеты не нужны.
В OpenCode заранее подключены Tokenator и Tavily. В действующем глобальном
конфиге OpenCode задано `"websearch": {"provider": "tavily"}`.
Скрипт не хранит API-ключи: использует существующие подключения OpenCode.

## Запуск

```bash
git clone https://github.com/Suntechnic/ai-monitor.git
cd ai-monitor
python3 ai_monitor.py
```

По умолчанию: tokenator/free-glm-5.3-flash и новости за 7 дней.

```bash
python3 ai_monitor.py --days 1 --timeout 1800
python3 ai_monitor.py --model tokenator/free-minimax-m3.1-flash
```

`--allow-paid-model` снимает проверку префикса модели. По умолчанию этот флаг
не нужен. Проверка имени не гарантирует бесплатность: актуальные условия Tokenator
нужно проверять в кабинете. Расходы Tavily отдельные: до 8 поисков — инструкция
агенту, не жёсткий программный лимит; кредиты не равны количеству поисков.

## Результаты

- `reports/` — итоговые Markdown-отчёты с уникальными именами.
- `runs/` — снимки источников, manifest, промпт, прошлый отчёт и логи каждого запуска.
- Ошибка завершает процесс с кодом 1, старые отчёты не перезаписываются.
- Параллельный запуск блокируется файловой блокировкой.
- Успешный выход: код 0 и путь нового отчёта в stdout.

Скрипт загружает официальные страницы DeepSeek/OpenCode и JSON OpenRouter,
а агент читает файлы, проверяет новости через Tavily и пишет report.md.
При недоступном поиске инструкция требует не публиковать отчёт.
Структурная проверка не доказывает правильность фактов: цены и рекомендации
могут требовать ручной проверки. Отчёт не заменяет тесты моделей на своих задачах.

## Безопасность и ограничения

OpenCode запускается с --auto: разрешения, не запрещённые явно, одобряются
автоматически. Рабочая папка отдельная, но это НЕ sandbox. Инструкция не выполнять
shell-команды не является техническим запретом. Для недоверенных веб-страниц
рекомендуется отдельный непривилегированный пользователь и ограничения инструментов
в вашей конфигурации OpenCode. Не запускайте от root.

Исходники и отчёты игнорируются Git. Скрипт не устанавливает cron/systemd,
не меняет глобальную конфигурацию и не включает платные поисковые тарифы.
Сеть и реальные подключения провайдеров проверяются только при запуске у вас.
