# ai-monitor

Короткий мониторинг ИИ для PHP/JS/Vue/HTML/CSS: DeepSeek, OpenRouter, OpenCode Go, Токенатор, Vantyr.
Планировщик не включён. Linux, Python 3.9+, OpenCode v2, PyYAML.

## Запуск

Установите зависимости: `python3 -m pip install -r requirements.txt`.
Скопируйте `providers.example.yml` в `providers.yml`, если локального конфига ещё нет.
В `providers.yml` настраиваются URL, формат, название и условия доступа каждого поставщика.
Поле `token` необязательно; если задано, скрипт отправляет `Authorization: Bearer <token>`.
Другой конфиг можно выбрать через `--config /absolute/path/providers.yml`.
`providers.yml` исключён из Git; в manifest и промпт ключи не копируются.

Задачи и их токенные профили описаны в `profiles.yml` (коммитится в Git):
`title` — название задачи, `input` / `output` / `cache_read` — оплачиваемые
токены условной задачи (типовой сессии целиком), `note` — происхождение цифр.
Чтобы добавить задачу, добавьте профиль — число строк таблицы в отчёте
изменится само. Цифры откалиброваны по средним реальных сессий OpenCode
(`opencode api get /api/session`) и обновляются вручную. Собирается окно из 200
последних сессий на машину; более старые не попадают в расчёт, поэтому цифры
редких задач переносите в `profiles.yml` заранее.
Другой файл профилей: `--profiles /absolute/path/profiles.yml`;
`--dry-run` готовит снимки, manifest и промпт и выходит до запуска OpenCode.

## Пометки сессий и калибровка

Числа в `profiles.yml` — средние по реальным сессиям. Сессии помечаются
типовым тегом, равным ключу профиля; каталог тегов берётся из `profiles.yml`,
а не из конфига плагина. Для пометок в TUI достаточно установленного плагина
[opencode-session-tags](https://github.com/isturiz/opencode-session-tags)
(одна строка в `cli.json`); теги хранятся в
`metadata["opencode-session-tags"]["tags"]`. Наш `tag` пишет тот же формат,
сохраняя рабочие теги плагина (`done`, `in-progress`...) — они в расчётах не участвуют:

```bash
python3 session_stats.py list              # все сессии: теги, папка, токены, $
python3 session_stats.py tag last php      # заменить типовой тег последней сессии
python3 session_stats.py tag <id-префикс> php-tosir
python3 session_stats.py tag <id-префикс> -   # снять типовой тег
python3 session_stats.py stats             # среднее и медиана по профилям
python3 session_stats.py show <id-префикс> # сырые поля сессии
```

В TUI: Ctrl+P → Edit current session tags (или `/session-tags`).
Добавление задачи: новый профиль в `profiles.yml` плюс тот же ключ
в `extraTags` плагина в `~/.config/opencode/cli.json`; строки отчёта и
словарь статистики расширятся сами. Теги плагина без одноимённого профиля
(`ai`, `scripting`) показываются отдельной строкой «вне каталога».
На одну сессию держите один типовой тег; при нескольких она попадёт
в каждую группу с предупреждением.

Порядок работы: завершили задачу — `tag last <ключ>` или пометка в TUI;
накопилось — `stats` и перенос средних (или медиан) в `profiles.yml`.
Теги локальны для машины: на другой ставится только плагин.

### Сбор статистики с других машин (по SSH)

Управляющая машина сама подключается к удалённым по SSH и запускает там
`export`. На удалёнке ничего не устанавливается: скрипт передаётся через stdin.
Нужны: SSH-доступ без пароля (`BatchMode=yes`), Python 3 и `opencode` на удалёнке.

```bash
cp stats-hosts.example.yml stats-hosts.yml   # заполните; файл исключён из Git
python3 session_stats.py collect             # локальная машина + все хосты + summary
python3 session_stats.py collect --host notebook   # только один хост
python3 session_stats.py collect --local     # только эта машина, без SSH
python3 session_stats.py stats               # таблица по снимкам, без записи
```

Снимки: `runs/session-stats/<host>.json` (`local.json` — эта машина), по одному на
хост, перезаписываются. Окно сбора — до 200 последних сессий каждого хоста по
времени обновления, без фильтрации по токенам; для каждой сессии читается вся
история сообщений, и из ответов ассистента извлекаются использованные модели
(провайдер + модель) со временем каждого ответа. Снимок формата 2 содержит эти
данные; снимки старого формата 1 читаются только для токенной статистики.
Если хост недоступен (или история какой-либо сессии не читается), его прежний
снимок сохраняется и участвует в расчёте, а команда завершается ненулевым кодом.
Дубликаты `(host, id)` берутся по наибольшему `updated`.

`runs/session-stats/summary.yml` пересчитывается при каждом `collect` и совместим
с `profiles.yml`: верхний уровень — теги, у каждого `title`, `input`, `output`
(среднее `output + reasoning`), `cache_read`, `note` с медианами. Служебные
сведения (источники, даты сбора, мультитеги) — в комментариях файла. Нужные блоки
копируйте в `profiles.yml` вручную; `profiles.yml` для сбора и расчёта не нужен.
Все теги попадают в summary, в том числе рабочие плагина; отбирайте сами.

### Статистика использованных моделей (models.yml)

`runs/session-stats/models.yml` пересчитывается при каждом `collect` рядом с
summary. Модели группируются по паре `providerID + model.id` (одинаковые модели
у разных провайдеров — разные записи). Использованием считается ответ
ассистента в сообщениях сессии; единица подсчёта — уникальная сессия,
а не отдельный ответ. Учитываются все сессии окна: с тегами, без тегов,
дочерние сессии субагентов и сессии с нулевыми токенами.

```yaml
tokenator:
  free-glm-5.3-flash:
    sessions: 12        # сессий с этой моделью во всей собранной выборке
    tags:               # объединение тегов этих сессий
    - admin
    - ai
    week: 11            # сессий за последние 7 дней
    month: 12           # сессий за последние 30 дней
    trand: 1000.0       # изменение week к предыдущим 7 дням, %
```

`trand` = (week − предыдущие 7 дней) / предыдущие 7 дней × 100: `null` — рост
с нуля (процент не определён), `-100.0` — использование прекратилось,
`0.0` — не использовалась в обоих периодах. Периоды считаются от момента
формирования файла по времени сообщений (не по времени обновления сессии,
которое меняется, например, при редактировании тегов). Долгое неиспользование
смотрите по `week: 0` при ненулевом `sessions`, рост активности — по `trand`.
`stats` показывает ту же таблицу в терминале и пересчитывает периоды
от текущего момента по сохранённым снимкам.

Ограничение: окно — 200 последних сессий каждого хоста. При высокой активности
30-дневный период может не покрыться выборкой, и `week`/`month`/`trand` будут
занижены; в этом случае в комментариях файла появляется предупреждение
«ВЫБОРКА ОБРЕЗАНА ЛИМИТОМ» (отдельно по каждому хосту). Снимки формата 1
без данных о моделях отмечаются предупреждением и в статистику моделей
не попадают.

В OpenCode должна быть доступна `opencode/glm-5.3-flash-free` (по умолчанию).
Подключите Tavily и задайте в глобальном конфиге
`"websearch": {"provider": "tavily"}`. Ключи в репозитории не хранятся.

```bash
python3 ai_monitor.py
python3 ai_monitor.py --days 1
python3 ai_monitor.py --model tokenator/free-glm-5.3-flash
```

## Результат

Каждый запуск создаёт папку `reports/<дата-время-суффикс>/` и копирует её содержимое в `reports/actual/`:

- `report.md` — таблица рекомендаций: по 2 роли на каждый профиль из `profiles.yml`, новости и изменения.
- `prices.md` — подробные цены, условия, расчёты и сравнение цен на модели, доступные у нескольких поставщиков.
  В сравнение также попадают модели из `runs/session-stats/models.yml`, если их тарифы
  подтверждены у 2+ поставщиков из `providers.yml`. Снимок статистики не обновляется
  автоматически; используйте `python3 session_stats.py collect` перед запуском монитора.
  Если снимка нет, раздел создаётся без использованных моделей.
- `sources.md` — источники, отзывы и основания оценок.

Поставщик и точный API ID обязательны для каждой рекомендации.
При отсутствии профильных бенчмарков агент использует отзывы и косвенные данные,
отмечая уверенность, но всё равно выбирает практический вариант.
Промпт редактируется отдельно в `prompt.md`.
Цены сначала берутся из загруженных снимков; недостающие сведения проверяются
по официальным URL. Поиск качества выполняется для уникальных моделей,
а цены и условия проверяются отдельно для выбранных поставщиков.

Старые одиночные отчёты `reports/*.md` также учитываются при сравнении.
Для сравнения берётся отчёт с самым свежим временем изменения файла.
Исходные снимки, manifest, промпт и opencode.log сохраняются в `runs/`.
Три файла публикуются одной операцией только после структурной проверки всех трёх.
Код выхода 0 и путь report.md означают успешную публикацию; при ошибке код 1.
Параллельные запуски блокируются. Фактическая корректность не гарантируется
структурной проверкой; реальное подключение проверяется локальным запуском.

## Расходы и безопасность

Без --allow-paid-model разрешены только модель по умолчанию и tokenator/free-*.
Имя модели не гарантирует неизменность тарифа. Tavily расходует отдельные кредиты.
До 8 поисков — инструкция агенту, а не технический лимит.
Используется --auto, отдельная рабочая папка НЕ sandbox. Запрет shell-команд
в промпте не является техническим ограничением. Не запускайте от root;
используйте ограничения инструментов и непривилегированного пользователя.
Скрипт не меняет глобальную конфигурацию и не подключает платные тарифы.

## Рекомендуемые провайдеры

[Токенатор](https://tokenator.cloud/?ref=760f8922)
- Очень большой выбор моделей
- Оплата рублями
- Есть дневной бесплатный лимит доступа к сильным моделям, в т.ч. Claude Opus 5.5 и Gemini 4 Argon
- Поддержка в Telegram на русском

[Vantyr](https://vantyr.xyz/sign-up?aff=wj46)
- Модели OpenAI и Anthropic
- Оплата криптой или иностранной картой
- Очень низкие цены
- Нестабильная доступность (бывают обрывы и отказы API), моделей мало

[DeepSeek](https://platform.deepseek.com/)
- Прямой поставщик
- Оплата иностранной картой
- Очень низкая цена за вполне приемлемую модель, особенно в OFF_PEAK (с 16:30 до 00:30 UTC, то есть с 19:30 до 03:30 по МСК (UTC+3))

[OpenRouter](https://openrouter.ai/)
- Очень много моделей
- Оплата иностранной картой
- При внесении однократно 10$ на счет, увеличиваются дневные лимиты на бесплатных моделях в 20 раз
- Среди бесплатных моделей нет ничего примечательного

[OpenCode](https://opencode.ai/)
- Есть подписка от 10$ с раздельными лимитами для моделей
- Оплата иностранной картой
- Моделей много, но в подписке флагманов OpenAI и Anthropic нет.
